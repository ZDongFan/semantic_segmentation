# 工作区 UI 改版

本轮实现信息纠正、统一推理入口和草稿查看操作。四个页签仍可独立进入，AI 编辑无需先完成模型推理。

## 界面与代码边界

- `workflow_ui.py`：工作摘要、输入详情折叠、三选一范围、参数恢复、按钮条件、草稿显示与可滚动布局。
- `land_cover_classification_dialog.py`：保留现有推理、ROI、草稿 generation、导出和 AI 业务入口；状态转换后合并刷新展示。
- `project_panel.py`：项目错误及原操作重试、同步 generation 标记、项目级发布条件、只读常用/全部字段预览。
- `land_cover_classification.py`：侧栏可调整宽度，记住用户偏好。
- `.ui` 保留基础控件与文案；运行时工作区组合由上述模块负责，新增模块已加入打包清单。

## 操作条件

| 操作 | 条件 | 不满足时 |
| --- | --- | --- |
| 开始推理 | 已关联有效影像、模型类别契约有效、runtime 解释器存在、无冲突任务；绘制模式还需同影像的有效范围 | 禁用并显示原因；启动时继续执行原有完整校验 |
| AI 启动 | 已关联有效影像、runtime 解释器存在、无冲突任务且未启动 AI | 显示前置条件；SAM 依赖仍仅启动时检查 |
| AI 添加 | 活动 AI 工具、有效预览、无预测/追加或其他冲突任务 | 禁用；地图 E 快捷键仍由原有地图工具处理 |
| 保存/预览/导出 | 当前 generation 与项目、影像关联正确，草稿图层有效且无冲突任务 | 提示当前没有可操作草稿；零要素不构成禁用条件 |
| 发布 | 已选项目，当前有可保存草稿、项目列表有已保存草稿或存在待确认发布请求之一；无冲突任务 | 发布仍执行服务端校验、保存和确认 |
| 撤销模型融合 | 已成功融合且尚未发生后续编辑 | 隐藏或禁用；启动、失败和取消不开放撤销 |
| 定位选中对象 | 当前有效草稿中存在选择 | 禁用 |

任务冲突包括项目请求/切换、主推理、输入转换、AI 预测/追加/加载和导出。按钮提示不替代业务入口校验。

## 数据与状态

- 项目错误只写项目页；模型扫描只写模型详情；推理、AI 和文件导出分别反馈。
- 推理空闲隐藏进度；融合期间显示不定进度，generation 发布成功才显示完成。取消不伪装成运行失败。
- 摘要的同步依据是服务端成功响应或成功恢复的影像与 generation 对应关系。几何编辑缓冲未提交时优先提示未提交，后续 generation 显示待同步。
- 切换影像清理对应任务反馈及上次导出入口。关闭仍沿用原有尽力保存规则。
- 属性表默认呈现类别、平方米面积、米制周长、制图者和来源编号；全部视图保留 24 列及完整编号提示，不改变底层字段、空值和几何测量方式。
- 草稿显示模式及不透明度只改变渲染，不改草稿数据；AI 预览为青色虚线临时对象。

## 2026-11-03：真实 UI、推理、AI 与发布验收

在 Windows QGIS 3.44.11 中，使用独立“UI改版验收_20261103”项目和真实影像的 768×768 有限窗口验证。既有业务项目与原始影像未修改；裁剪影像、导出文件和验收日志为本机临时资产，不作为产品默认配置。

- 项目服务恢复后，通过项目页重试成功读取列表，旧连接错误消失。
- 通过统一“开始推理”按钮执行真实 PyTorch bundle 全图推理（范围为验收小窗口），使用相交 DEM，实际有效覆盖率 100%；得到 10 个 inference 草稿要素，完成后进入草稿编辑页。
- 真实 SAM2 权重加载、画布鼠标松开触发预测及 E 键追加通过，生成 1 个 origin=user 要素，草稿共 11 个。最终版本再测正负点预测，负点未被预览覆盖；切换地图工具、恢复 AI 点选、清空和停止均通过。
- 三种格式均通过真实导出按钮写出。GeoTIFF 为 768×768、256×256 分块 BigTIFF；Shapefile 回读 20 个公开字段、10 个最终斑块（按既有 dissolve 规则合并）；DXF 文件成功生成。

### 本轮实机发现并修复

1. 刷新装饰器把无参 Qt 槽包装为变参槽，导致 clicked(bool) 被误传入 AI 启动、导出等方法。现在保留无参包装签名，新增真实 QPushButton 点击测试。
2. 普通 Python UI 控制器在面板销毁后仍接收外部画布信号，访问已删除 QTimer。现在继承 QObject 并以对话框为父对象，使用 pyqtSlot 管理接收者寿命，同时对已删除对象防护；新增窗口销毁后真实画布切换测试。
3. AI 追加确认当前影像关联时被自身忙碌状态拦截。相同影像与 DEM 的无操作绑定先返回，实际登记或切换仍检查忙碌；新增真实追加及切换保护测试。
4. 网络请求线程 finished 后提前 deleteLater，进度框关闭的事件处理可能在结果读取前删除线程。调用栈持有线程至结果读取完成，退出后后台线程仍自行释放；新增进度框关闭时强制处理 DeferredDelete 的竞态测试。

最终相关回归 73 项通过，覆盖以上新用例及既有项目保存/恢复、退出网络、三种导出、generation、AI 快捷键和鼠标行为。本轮为功能与交互验收，不是模型精度评估；未覆盖非 Windows、整幅超大影像推理、生产网络部署或大规模属性表性能。原有 ROI 三角形边界断言失败仍单独记录，未修改其算法或期望。
