# 本地工作区

项目页提供新建、打开、最近项目、管理影像、保存草稿、预览当前滑坡列表、恢复管理和上传占位入口。工作流不连接后台服务。“上传成果”只有项目内存在已保存草稿时可点击，点击仅提示尚未接入。

工作摘要区分尚无草稿、编辑尚未提交、当前草稿待保存、已本地保存以及保存失败。文件导出不改变本地保存状态。详细项目存储及恢复约定见 [local_project.md](local_project.md)。

左上摘要标题为“当前项目”。输入影像详情及模型目录、刷新入口、扫描结果始终展开。草稿编辑不提供显示模式或不透明度选择，沿用默认图层样式；“放大当前选中滑坡”定位地图选中要素，“添加到滑坡草稿(快捷键E)”保留 E 键追加行为。

创建或打开项目时自动创建项目文件夹下的 `output` 目录，并将其设为默认导出目录。用户仍可自行选择导出目录，同一项目切换影像时保留该选择；切换项目后恢复为目标项目的 `output`。若同名文件阻止创建目录，项目打开失败并保留原会话。

模型推理继续提供全图、当前画布和绘制范围；ROI、halo、用户区域优先及一次性融合撤销规则不变。只有成功融合才提供撤销，后续编辑使旧撤销失效。推理、AI、项目和导出反馈分别显示。

选择影像文件和推理完成后保持当前页签，不自动跳转到草稿编辑；需要编辑时由用户手动选择页签。

当前滑坡列表为非模态只读窗口，表格和草稿选择双向联动，每页最多 200 个。常用字段包括类别、面积、周长、WGS84 中心经度和中心纬度、制图者、来源编号；经纬度显示七位小数。常用/全部字段视图只改变展示，不改变 17 个标准字段、NULL 或底层精度。窗口固定项目和影像身份，generation 变更刷新，切换或图层销毁使旧窗口失效。

“查看单个滑坡属性”位于项目页“预览当前滑坡列表”下方，无需打开列表即可启用地图左键点选。详情使用独立非模态工具窗口，不占用“地物分类”插件主体或页签空间；首次显示和关闭后重开时默认靠地图画布右下角，并限制在当前屏幕可用范围内。窗口可拖动、关闭，连续点选更新同一窗口且保留拖动位置。类别/来源编号、面积/周长、中心经度/中心纬度各占一行，制图者独占一行；面积和周长附带单位，未赋值显示“未填写”。不显示“只读”文字、定位或复制按钮，文本仍可选择复制。关闭详情窗口会退出点选并恢复原地图工具；Esc 或再次点击入口退出点选并保留详情。切换页签保留窗口，切换项目/影像、草稿换代、图层移除或关闭插件会清除并隐藏旧详情。查询不修改草稿属性。

恢复管理只读取当前项目影像登记的本地历史。恢复前校验身份、SHA-256、CRS、边界、类别、UUID 和几何，提交当前编辑并保留恢复前快照引用；取消或失败保留当前草稿。不会扫描系统临时目录、请求服务或自动导入旧项目。

相关回归为 `test_workflow_ui`、`test_independent_workspaces`、`test_project_workflow`、`test_project_exit` 和 `test_image_membership`，均使用真实 QGIS 控件及合成数据。
